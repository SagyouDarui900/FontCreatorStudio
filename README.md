# 和文手書きフォント・作字スタジオ (Japanese Handwriting Font Studio)

ブラウザ上でひらがな、カタカナ、英数字、記号、JIS漢字（第一水準〜第三水準・教育漢字）の手書きおよびベクター作字を行い、フォントファイルを出力するWebアプリケーションです。

TrueType（`.ttf`）、OpenType（`.otf`）、Webフォント（`.woff` / `.woff2`）、ベクター（`.svg`）、iOS/iPadOS構成プロファイル（`.mobileconfig`）形式での出力に対応しています。

PC（マウス・液晶ペンタブレット）、タブレット（iPad / Apple Pencil）、スマートフォン（タッチ操作）で動作します。PWA（Progressive Web App）に対応しており、オフライン環境でも動作します。

## 主な機能

### 1. PWA・オフライン動作
- **キャッシュ管理**: Service WorkerによりHTML、JavaScript、CSS、フォントデータを端末に保存し、ネットワーク未接続時でも動作します。
- **PWAインストール**: Chrome、Edge、Safari（iOS / iPadOS）、Androidの各ブラウザからホーム画面やデスクトップへインストールできます。
- **接続状態表示**: オフライン状態を検知し、画面上に状態を表示します。

### 2. データ保存と履歴管理
- **IndexedDB最優先の復元**: 起動時にIndexedDBからプロジェクトデータを読み込みます。LocalStorage（約5MB）の上限を超える大容量プロジェクトでも、データの欠落や上書きを防ぎます。
- **文字ごとの履歴管理 (Undo / Redo)**: 編集履歴を作業中の文字（Unicode）単位で独立して保持します。文字を切り替えた際に別の文字の履歴が混ざる動作を防ぎます。
- **バックアップ管理**: IndexedDB内に世代管理されたスナップショットを保存し、任意の復元ポイントへ戻すことができます。
- **ファイル入出力**: プロジェクトファイル（`.fontproj.json`）の書き出しと読み込みに対応しています。

### 3. 手書き・ベクター作図機能
- **ブラシツール (`B`)**:
  - Catmull-Romスプライン曲線を用いたストローク補間。
  - スタイラスペンの筆圧感知（Apple Pencil対応）。筆圧感度の切り替え（高 / 標準 / 低 / OFF）および筆圧曲線の調整。
  - 毛筆、万年筆、Gペン、ミリペン、平筆、マーカーなどのプリセット。カスタム設定の保存・読み込み。
  - 手ブレ補正強度（強 / 標準 / 弱）の指定による線の平滑化。
  - 線の交差部における重なり白抜きの自動処理（`fillRule="nonzero"`）。
- **ベクターペンツール (`P`)**:
  - クリック操作で角（コーナー点）、ドラッグ操作で方向線（ハンドル）を持つ曲線点（スムーズ点）を配置。
  - 上部サブツールバーに「確定」「1点戻す」「破棄」の操作ボタンを配置。
  - キーボード操作への対応:
    - `Enter`: 開いたパス（線）のまま確定。
    - `Backspace` / `Delete`: 直前の1点を削除。
    - `Esc`: 描画中のパスを破棄。
    - 始点ノード付近をクリック: パスを閉じて確定。
- **ノード編集ツール (`A` / `V`)**:
  - 選択中のノードまたは輪郭を矢印キーで微調整（通常1px、`Shift`併用で10px、`Alt`併用で0.1px）。
  - `Shift` + クリックによる複数ノードの追加選択と連動移動。
  - `C` キーによるノード属性（スムーズ／コーナー）の切り替え。
  - ノードの追加・削除、方向線（ハンドル）の個別調整。
- **スマートスナップ機能**:
  - 仮想ボディ（1000×1000）、字面枠（820×820 / 850×850）、ベースライン、キャップハイト、アセンダー、ディセンダー、中心線、同一輪郭内の他ノードへのスナップ（近接8px以内）。
- **図形ツール (`U` / `O`)**:
  - 矩形ツール（`U` / `S`）および楕円ツール（`O`）による基本図形の作成。
  - `Shift` キー併用による正方形・正円の作成。
- **パス演算・最適化**:
  - 輪郭の結合（Union）、交差（Intersect）、差分（Subtract）。
  - パス単純化（Simplify）による不要ノードの自動削減。
  - ストロークのアウトライン化（Expand Stroke）。

### 4. 作図補助・ガイド
- **作図基準枠**:
  - 仮想ボディ枠（1000 UPM基準）。
  - 漢字字面枠（85% / 850×850）、仮名字面枠（78% / 780×780）、小書き字面枠（82% / 820×820）。
- **補助グリッド**:
  - 田字格、十文字格、米字格、九宮格、回字格、同心円格、3×3格、黄金比ガイド、欧文4線ガイド。
- **カスタムガイド線**:
  - 定規領域からのドラッグ操作による水平・垂直ガイド線の配置。
- **下絵・前後グリフ表示**:
  - 前後の文字や参照文字を半透明で重ねて表示。
  - 端末内の画像ファイル（JPG / PNG / SVG）を下絵として読み込み、不透明度と縮尺を調整して下敷きに表示。

### 5. 組版設計・フォント出力
- **出力形式**:
  - TrueType (`.ttf`)、OpenType (`.otf`)、Webフォント (`.woff` / `.woff2`)、ベクター (`.svg`)、iOS/iPadOS構成プロファイル (`.mobileconfig`)。
- **OpenType機能**:
  - 縦書き置換機能（`GSUB vert`）: 句読点、括弧、長音符、小書き仮名の縦書き用グリフ置換テーブルの生成。
  - プロポーショナル字幅（`GPOS kern` / `GSUB palt`）の定義。
- **メトリクス調整**:
  - 文字の送り幅（Advance Width）および左右余白（LSB / RSB）の調整。
  - 輪郭境界に基づく左右余白の自動計算。
- **組版プレビュー（試し打ち）**:
  - 編集中のグリフをブラウザ内でフォントデータにコンパイルし、縦書き・横書きでの文章組版表示を確認。

## 主なキーボードショートカット

アプリ内で `?` キーを押すとショートカット一覧モーダルを表示します。

### ツール切り替え
| キー | 機能 |
| :--- | :--- |
| `B` | 筆・ブラシツール |
| `P` | ベクターペンツール |
| `V` | 選択・移動ツール |
| `A` | ノード編集ツール |
| `E` | 消しゴムツール |
| `U` / `S` | 矩形（長方形）ツール |
| `O` | 楕円・円ツール |
| `R` | 定規・距離計測ツール |
| `H` | 手のひらツール（キャンバス移動） |

### 描画・ノード編集
| キー | 機能 |
| :--- | :--- |
| `[` / `]` | ブラシ / 消しゴムサイズの縮小・拡大 (-2px / +2px) |
| `Shift` + `[` / `]` | ブラシサイズの縮小・拡大 (10px単位) |
| `Shift` + ドラッグ | 直線描画（水平・垂直・45度） |
| `Shift` + クリック | 複数ノードの追加選択（ノード編集時） |
| `↑` `↓` `←` `→` | 選択中のノード・輪郭の移動（1px単位） |
| `Shift` + 矢印キー | 選択中のノード・輪郭の移動（10px単位） |
| `Alt` + 矢印キー | 選択中のノード・輪郭の移動（0.1px単位） |
| `C` | 選択中ノードのスムーズ（曲線）/ コーナー（角）属性の切り替え |
| `Enter` | ペン作図の確定（開いたパスのまま保存） |
| `Backspace` / `Delete` | ペン作図中は直前の1点を削除。通常時は選択要素を削除 |
| `Ctrl` / `Cmd` + `Z` | 取り消し (Undo) |
| `Ctrl` / `Cmd` + `Shift` + `Z` | やり直し (Redo) |
| `Ctrl` / `Cmd` + `A` | 現在の文字の全輪郭を選択 |
| `Alt` + `S` | パスの単純化（ノード数削減） |
| `Shift` + `Alt` + `S` | 左右余白（サイドベアリング）の自動設定 |

### 表示・画面操作
| キー | 機能 |
| :--- | :--- |
| `Space` + ドラッグ | キャンバスのパン移動 |
| `0` | 全体表示（画面に合わせる） |
| `1` | 等倍表示 (100%) |
| `W` | 幅に合わせる |
| `+` / `-` | 拡大 / 縮小 |
| `F` | 集中モード（全画面表示）の切り替え |
| `\` | 文字一覧サイドバーの表示・非表示切り替え |
| `G` | ガイド線の表示・非表示切り替え |
| `Esc` | ペン描画の破棄 / 選択解除 / 開いているモーダルを閉じる |

## 開発・ビルド手順

### 必要な環境
- Node.js 18.0.0 以上
- npm 9.0.0 以上

### コマンド一覧
```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (ポート 3000)
npm run dev

# 型チェック (TypeScript)
npm run lint

# 単体テストの実行 (Vitest)
npm run test

# 本番用ビルド (dist ディレクトリに出力)
npm run build
```

## 用語定義

- **UPM (Units Per Em)**: フォントの仮想正方形（Em square）の基準解像度。本アプリでは 1000 UPM を標準値としています。
- **仮想ボディ**: 文字を配置する正方形の基準枠（1000×1000）。
- **字面枠（じづらわく）**: 仮想ボディの内側にある、実際の文字の線画が収まる推奨領域。漢字は850×850、仮名は780×780、小書き文字は820×820を目安とします。
- **サイドベアリング (LSB / RSB)**: 文字の輪郭の左端・右端から、文字枠の境界までの余白幅。文字同士が衝突しないための間隔を決定します。
- **ベジェ曲線**: 始点、終点、および方向線（ハンドル）で定義されるパラメトリック曲線。三次ベジェ曲線（Cubic Bezier）を用いて滑らかな曲線を表現します。
